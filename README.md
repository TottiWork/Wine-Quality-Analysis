# Wine-Quality-Analysis
Dataset kualitas anggur mencakup atribut fisikokimia seperti asam tetap, gula sisa, alkohol, dan pH, yang mempengaruhi rasa dan kualitas anggur. Fitur-fitur ini digunakan untuk memprediksi kualitas anggur yang dinilai antara 3 hingga 8. Analisis data mining membantu pembuat anggur mengidentifikasi faktor penting yang memengaruhi kualitas.
